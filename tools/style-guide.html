How to use this page

Everything below renders with the site's real, live CSS — what you see is what it will look like once pasted into a guide. Edit the sample text where offered, then use Copy HTML and paste into a Rich Text/HTML box via Edit HTML Source (never the plain visual editor — see CLAUDE.md on why). This page itself isn't a paste target; it only exists to generate snippets for you to use elsewhere.

Headings

Guide content headings follow one site-wide baseline (Bootstrap 5's own default scale), regardless of which page you're on. H1 is reserved for the guide's own title, set automatically by LibGuides. H2 is effectively reserved too — it's the same size/weight/color a box's own Title field renders at (see Box Titles below), so an H2 typed into box content would look identical to a real box title and read as confusing/duplicated. Start your own content headings at H3.

Box Titles

Set via each box's own Title field in LibGuides Admin — not pasted HTML, so there's no snippet to copy here. Shown for reference so you know what it'll look like; it follows the same size/weight/color as an H2 (which is why H2 is reserved — see note above).

Alerts

For a single callout — a heads-up, a caution, a confirmation. Standard Bootstrap .alert component and variant classes (so any Bootstrap reference applies), with a left accent border and icon instead of Bootstrap's flat pastel block, matching the rest of the site's accent language.

Feature Cards

Based on the "Core Services" cards on the library homepage — an icon, a title, a short description, and an optional call-to-action button. Good for highlighting 2-4 services or resources side by side.
